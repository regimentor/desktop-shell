# Космическое оформление лаунчера — прототип

Вопрос: какое hi-tech оформление подходит компактному лаунчеру Daevox?
Варианты сохраняют назначение оболочки: приложения, звук и уведомления.

Запуск из корня: `python3 launcher/cosmic-preview.py`.
Адрес: http://127.0.0.1:8767/cosmic-prototype.html?variant=A.
HTML также открывается напрямую, без сервера и внешних запросов.

- A / Halo: окно 560 px, список приложений, отдельные переключатели режимов.
- B / Eclipse: окно 520 px, плотный список и встроенные вкладки.
- C / Orbit: окно с боковыми переключателями и двухколоночной сеткой приложений.

Поиск фильтрует приложения по имени, описанию и ключевым словам.
↑/↓ выбирают результат; Enter из поиска имитирует запуск, закрывая окно.
Escape очищает запрос, затем закрывает окно. Кнопка возвращает лаунчер.
Alt+1/2/3 переключают режимы. Варианты выбираются нижней полосой или
←/→ вне полей ввода; выбранный вариант сохраняется в URL.

Громкость, mute, выбор устройства, удаление уведомлений и «Не беспокоить»
меняют только данные в памяти. Приложения и устройства не опрашиваются;
реальный запуск, аудиоуправление и D-Bus не подключены.
Вариант оформления пока не выбран для реализации в QML.
