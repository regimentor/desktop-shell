# Daevox Shell

Пользовательская оболочка с лаунчером приложений, управлением звуком и панелью рабочего стола.

## Language

**Панель**: Постоянная верхняя полоса рабочего стола на каждом мониторе, объединяющая воркспейсы, заголовок окна, часы и дату, раскладку и системный трей.

**Иконка окна**: Отдельное представление открытого окна внутри его воркспейса на панели. Несколько окон одного приложения представлены несколькими иконками.

**Режим лаунчера**: Раздел лаунчера, определяющий назначение поиска и доступные действия. Apps предназначен для приложений, «Звук» — для управления воспроизведением.
«Уведомления» предназначен для просмотра истории уведомлений и доступных действий приложений.

**Центр уведомлений**: Раздел лаунчера с историей сообщений от приложений, доступными действиями и удалением отдельных записей или всей истории.

**Стопка уведомлений**: Группа сообщений одного приложения, которую можно
раскрыть для просмотра отдельных уведомлений и свернуть в компактное представление.

**Всплывающее уведомление**: Представление нового сообщения приложения поверх рабочего стола.

**Прочитанное уведомление**: Уведомление, закрытое пользователем или исчезнувшее
с экрана по таймеру. Просмотр истории и скрытие режимом «Не беспокоить»
сами по себе не означают прочтение.

**Временное уведомление**: Сообщение, которое приложение пометило как
не предназначенное для сохранения в истории центра уведомлений.

**Режим «Не беспокоить»**: Режим, скрывающий всплывающие уведомления с сохранением сообщений в истории центра уведомлений.

**Звуковое приложение**: Приложение с существующим аудиопотоком, в том числе на паузе или с выключенным звуком. Объединяет потоки под общим управлением, сохраняя отдельное управление громкостью и mute каждого потока.

**Поток приложения**: Отдельный звуковой поток внутри звукового приложения со своей громкостью и mute. Пользовательский пример — звук вкладки браузера, если она представлена отдельным потоком.

**Устройство вывода**: Устройство, на котором воспроизводится звук приложения.
_Avoid_: Источник вывода.

**Общая громкость**: Громкость текущего устройства вывода по умолчанию, показываемая системным ползунком лаунчера.

**Системный mute**: Отключение звука текущего устройства вывода по умолчанию с сохранением индивидуальных настроек приложений и потоков.
_Avoid_: Полный mute всех устройств.
