# Реализация и рабочее переключение

Дата: 2026-09-06. Спецификация подтверждена пользователем; реализация установлена
в существующий лаунчер, рабочий D-Bus переключён на Daevox.

## Что сделано

- Постоянная модель уведомлений, архив, DND, очередь до трёх карточек,
  replacement без дублей и отсчёт срока только после показа.
- Режим Alt+3 со стопками, поиском, действиями, быстрым ответом и Backspace.
- Всплывающие карточки с паузами таймера, фокусом после нажатия «Ответить»,
  подавлением на блокировке и при неизвестном состоянии.
- Нативный модуль внутри процесса: D-Bus endpoint, изображения/атомарный архив,
  Wayland lock observer. Причина собственного endpoint описана в
  [ADR](../../docs/adr/0001-notifications-in-process.md).
- Установщик собирает модуль до остановки лаунчера. По умолчанию runtime
  уведомлений загружается только после явного включения при миграции.
- Скрипт обратимой миграции с резервными копиями и защитой отката от перезаписи
  изменений, сделанных после переключения.

## Проверено

- 9 тестов модели: очередь, replacement, DND/lock, hover/reply/critical,
  удаление стопки, transient, восстановление архива, лимиты, мониторы и поиск.
- D-Bus на частной шине без системной активации: Notify, 1000 ms, replacement,
  новые подписи действий, доставка ActionInvoked/NotificationReplied постоянному
  клиенту, resident, transient, CloseNotification, image-data, рестарт и очистка.
- Отдельный тестовый Wayland-сервер: начальный locked, unlock/lock, потеря
  соединения → unknown, reconnect с начальным unlocked.
- Реальный Wayland UI с вымышленными данными: Alt+3, стопки/Enter, поиск,
  Backspace в поле, удаление стопки, черновик/Esc, закрытие и запрет открытия
  лаунчера при блокировке. Подключены и проверены загрузкой popup-компоненты.
- Основной shell.qml успешно загружает runtime и регистрирует endpoint.
- Сборка нативного модуля с -Wall -Wextra -Werror; повторная установка в
  изолированной файловой системе; тест обратимых правок миграции.
- Существующие JS-тесты аудио и панели проходят. В рабочей сессии audioReady=true.
- Рабочая D-Bus-активация после остановки лаунчера возвращает
  `('Daevox', 'Daevox', '1.0', '1.2')`.
- После контролируемого SIGKILL MainPID сменился, сервис автоматически
  восстановился, endpoint готов. Наблюдатель затем подтвердил unlocked.
- Отправлено тестовое сообщение Daevox; в истории осталась прочитанная запись
  после истечения срока. Содержимое чужих уведомлений не запрашивалось.

Последний полный изолированный прогон и снимки:
`/tmp/daevox-notification-test.fgjb6_zm/`.
Предупреждения PipeWire/Hyprland IPC в нём относятся к изолированному runtime;
получение текущей блокировки через Wayland проверено как unlocked.

## Миграция

Владелец org.freedesktop.Notifications совпадает с процессом существующего
`daevox-launcher.service`. Прямой запуск mako удалён из Hyprland Lua.
Пользовательская D-Bus активация направлена на этот же launcher unit;
его drop-in включает DAEVOX_NOTIFICATIONS=1 и Type=dbus.

Резервная копия:
`/home/evgen/.local/state/daevox/notification-migration/1788711901749430231`.

Откат из корня репозитория:

```bash
python3 scripts/notification-migration.py rollback /home/evgen/.local/state/daevox/notification-migration/1788711901749430231
```

## Осталось для окончательной приёмки

- Проверить новый вход в рабочую сессию и сообщения реальных приложений,
  включая их кнопки/быстрый ответ. Тесты используют вымышленные сообщения.
- Физическое отключение монитора и реальный цикл блокировки/разблокировки
  не выполнялись; логика покрыта моделью, наблюдатель — тестовым протоколом.
- После приёмки удалить пакет mako. Сейчас он оставлен для отката и не является
  владельцем D-Bus; прямой автозапуск и его D-Bus активация заменены.

## Уточнение отображения изображений

По запросу пользователя image-data/image-path трактуются как метаданные
уведомления: компактный аватар в заголовке карточки и на обложке стопки,
без крупного блока вложения. При ошибке или отсутствии — иконка приложения,
затем первая буква. Схема архива сохранена, старые картинки получают ту же
трактовку. Изображения непосредственно в body не относятся к аватару;
поддержка body-images/markup этим изменением не добавляется.

Проверены тестовые аватары и fallback в настоящем Wayland-окне;
полный изолированный прогон: `/tmp/daevox-notification-test.bagcoay0/`.

## Компактные кнопки управления

По запросу пользователя табы Apps/Volume/Уведомления показывают только иконки,
без названий и подписей хоткеев. DND, фильтр сообщений и очистка всей истории
также стали иконками. Удаление карточки и стопки — корзина справа сверху;
у popup на этом месте крестик закрытия с сохранением истории. Кнопки имеют
подсказки и доступные имена; активное состояние выделено цветом.
