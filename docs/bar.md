# Панель Daevox

Quickshell 0.3.1, Hyprland 0.56.2. Верхняя панель на каждом экране:
воркспейсы с отдельной иконкой каждого окна, заголовок, трей, раскладка,
дата и время. Высота 30 px, внешний отступ 6 px, резервирование 36 px.

Для иконок панель использует Adwaita (пакет `adwaita-icon-theme`), включая
символические иконки меню Bluetooth. Настройка действует только на процесс
панели. `UseQApplication` в `shell.qml` включает поддержку контекстных меню трея.

## Запуск

```bash
qs --no-duplicate --log-rules 'quickshell.io.socket.warning=false' --path ./bar/shell.qml
```

Установка из любого рабочего каталога, от обычного пользователя:

```bash
/path/to/daevox-shell/install-bar.sh
systemctl --user status daevox-bar.service
```

Установщик включает сервис и запускает его в активной графической сессии.
Перед установкой завершите ручную копию панели. Launcher устанавливается
отдельно через `install-launcher.sh`; его команда открытия не меняется.

```bash
systemctl --user stop daevox-bar.service
systemctl --user restart daevox-bar.service
journalctl --user -u daevox-bar.service -b
```

## Поведение

- Номер/фон воркспейса переключает его; иконка фокусирует конкретное окно.
  При наведении интерактивные элементы меняют фон и показывают курсор-руку.
  Подсветка активного воркспейса и цвет его номера переходят за 150 ms.
  Клик сохраняет курсор в области панели: переключение и восстановление
  координат выполняются одним синхронным IPC-пакетом. Глобальные настройки
  курсора Hyprland не меняются.
  Колесо не переключает воркспейсы. Окна одного приложения не объединяются.
- Сначала сокращается центральный заголовок, затем уплотняются воркспейсы.
  Все иконки остаются в одной строке; при крайней нехватке места масштабируются
  и подписи. Неограниченное число окон не гарантирует читаемого размера.
- Special идут после обычных; один обозначается `S`, несколько — именами.
- Заголовок относится к текущему воркспейсу соответствующего монитора,
  включая открытый special. Пустой воркспейс не имеет заголовка.
- Клик по раскладке выбирает следующую раскладку основной клавиатуры.
- Трей показывает все элементы, включая passive. Левый клик активирует
  приложение, правый открывает меню; у `onlyMenu` левый также открывает меню.
  Средний клик и колесо передаются приложению. Поддержка зависит от приложения.
- Часы используют местное время в формате `dd.MM.yyyy  HH:mm`.

## Устройство

`HyprlandIpc.qml` содержит прямой клиент Unix-сокетов. Сначала открывается
поток событий, затем последовательно читаются полные JSON-ответы. Ответ
завершается закрытием request-сокета, а не первым read. Каждое соединение
получает свою эпоху; поздние ответы после сбоя игнорируются.

`HyprlandState.qml` объединяет события с задержкой 40 ms и обновляет только
связанные снимки. В спокойном состоянии опроса по таймеру нет. После таймаута,
обрыва, неподдерживаемой версии или некорректного ответа состояние очищается,
действия блокируются; часы и трей продолжают работать. Задержка повторного
подключения растёт от 250 ms до 8 s. Команды не воспроизводятся после сбоя.

В unit отключено низкоуровневое предупреждение Socket: Quickshell пишет
`PeerClosedError` и при штатном завершении каждого ответа Hyprland. Ошибки
самого клиента по-прежнему записываются в журнал с префиксом `bar:`.

`StateModel.js` отвечает за порядок окон, историю фокуса, группы и подписи.
`AppIconResolver.qml` использует DesktopEntries и системные иконки с кэшем;
если системная запасная иконка тоже отсутствует, используется `application.svg`.

Панель не импортирует `Quickshell.Hyprland` и не запускает `hyprctl`.
Синтаксис команд сверён с [официальными dispatchers](https://wiki.hypr.land/Configuring/Basics/Dispatchers/)
и проверен на установленной версии. Полный перезапуск compositor требует
нового процесса в новой Wayland-сессии и нового окружения.

## Общая тема

Единственный источник цветов и шрифта — `shared/DaevoxTheme.qml`.
Геометрия остаётся в локальных `Theme.qml`. В каждом runtime ссылка
`shared → ../shared` позволяет импортировать тему через `import "shared"`.
Прямой `../shared` из согласованной спецификации оказался несовместим с
[ограничением Quickshell на файлы вне конфигурации](https://quickshell.org/changelog/#v020).
Ссылка сохраняет общий источник и согласованное расположение установки:

```text
~/.config/quickshell/
├── shared/DaevoxTheme.qml
├── shared/qmldir
├── daevox-launcher/shared -> ../shared
└── daevox-bar/shared -> ../shared
```

Оба установщика заменяют общие файлы атомарно и сохраняют посторонние файлы
в `shared`. Прототип не устанавливается.

## Проверки

Из корня проекта:

```bash
node tests/bar/model.test.cjs
python3 tests/bar/transport.test.py
python3 tests/bar/install.test.py
bash -n install-bar.sh install-launcher.sh
/usr/lib/qt6/bin/qmllint -I /usr/lib/qt6/qml bar/*.qml
```

Транспортные тесты требуют разрешения создавать Unix-сокеты в `/tmp`;
они используют offscreen Qt и не подключаются к Hyprland. Проверяются
частичные JSON/UTF-8, события во время снимка, неизвестные события,
некорректные данные, таймаут, поздний ответ, разрыв и отсутствие повторной
отправки команды. Тест установки использует `bwrap`, временную `.config`
и подставной systemctl; реальная установка пользователя не изменяется.

Qt6 qmllint оставляет предупреждения метаданных Quickshell: PanelWindow
объявлен не создаваемым до регистрации Wayland backend, тип параметра
`QLocalSocket::LocalSocketError` отсутствует в qmltypes. Оба пути проверены
живым запуском и транспортными тестами.

Живые короткие проверки, автоматически закрывающиеся:

```bash
qs --no-color --log-rules 'quickshell.io.socket.warning=false' --path tests/bar/ui.qml
qs --no-color --log-rules 'quickshell.io.socket.warning=false' --path tests/bar/dense.qml
```

`ui.qml` проверяет геометрию на всех экранах, `dense.qml` — 30 тестовых окон
на ширине 1024 px и отсутствующую иконку. `commands.qml` проверяет фокус и
временно переключает раскладку, возвращая исходную; запускать, когда не
вводится текст. При принудительном прерывании восстановите раскладку вручную.

Результаты конкретного прохода и оставшиеся ручные проверки:
[отчёт реализации](../.scratch/bar/implementation.md).
