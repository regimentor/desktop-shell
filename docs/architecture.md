# Устройство единой оболочки

Единственный production `shell.qml` создаёт общие экземпляры и внешний IPC.
`UseQApplication` поддерживает меню трея; Adwaita задаёт тему иконок всего процесса.

| Модуль | Ответственность и зависимости |
| --- | --- |
| `desktop/DesktopState.qml` | Состояние Hyprland, раскладка, активный монитор, группы и заголовки, команды рабочего стола. Транспорт и преобразования снимков находятся рядом. UI не импортирует. `canChangeLayout`, `globalPosition`, `windowActive` и `windowUrgent` дают представлениям нужные данные без чтения внутренних снимков. |
| `bar/BarRuntime.qml` | Получает `desktop`, создаёт общие часы и резолвер иконок; `Variants` создаёт панель каждого экрана. |
| `launcher/Launcher.qml` | Получает `desktop` и nullable `notifications`; владеет поиском, выбором, `AppModel`, `audio/AudioModel` и `audio/AudioRouter`. Сохраняет `HyprlandFocusGrab`. |
| `notifications/NotificationRuntime.qml` | Получает `desktop`, создаёт единственную модель и всплывающие окна. Загружается только при `DAEVOX_NOTIFICATIONS=1`. |
| `notifications/NotificationPane.qml` | Встраивается в лаунчер; получает модель, тему, поиск и обработчик клавиш. Карточки используются также всплывающими окнами. |
| `shared/` | Единственный источник цветов и шрифта, `Icon` и `IconButton`. Геометрия остаётся в локальных темах владельцев UI. |
| `Daevox/Notifications/` | Нативный endpoint, архив и наблюдение блокировки; только `NotificationModel` импортирует этот модуль. |

Лаунчер предоставляет `open`, `openMode`, `toggle`, `close`, `status`.
`openMode` принимает `apps`, `audio`, `notifications` и один раз подготавливает
окно. Корневой IPC сохраняет target `launcher` и прежние команды/поля JSON.
Если панель в будущем запросит режим сигналом, его подключает корень;
доступ к внутренностям лаунчера из панели не требуется.

Активный монитор берётся из общего снимка `DesktopState`. `screenFor(screens)`
выбирает его среди доступных экранов; при неизвестном имени возвращает первый
по имени, при отсутствии экранов — `null`. Лаунчер не открывается без экрана;
при удалении текущего экрана закрывается и выбирает доступный. Всплывающие окна
также получают выбор экрана от общего состояния. На hotplug создаются окна,
а не новые модели и серверы. Отдельного опроса раскладки лаунчером больше нет.

Существующий транспорт сохраняет подписку до получения снимка, объединение
событий, поколения запросов, таймауты и переподключение. При потере соединения
состояние очищается, действия не ставятся в очередь до готовности. Часы, трей,
каталог приложений, звук и уведомления не зависят от готовности Hyprland.

Общие экземпляры живут до завершения оболочки. Закрытие лаунчера не уничтожает
модели и не выключает endpoint. Перезапуск единственного сервиса прерывает все
модули; сохранённые уведомления восстанавливаются без живых действий.

Установка доставляет только runtime-файлы в один самодостаточный каталог.
`install-shell.sh` и `uninstall-legacy.sh` используют одну библиотеку
`scripts/lib/legacy-installation.sh` с реализацией операций в `installation.py`.
Явные manifests позволяют удалить прежние файлы после реорганизации исходников.
Сборка и QML-проверка предшествуют остановке сервисов. Активация подтверждается
IPC; при отказе восстанавливаются прежняя конфигурация и состояния сервисов.
Пользовательский Hyprland-конфиг изменяется вручную. Подробные команды — в README.
