## Agent skills

### Issue tracker

Issues live as local Markdown under `.scratch/<feature>/`.
Read `docs/agents/issue-tracker.md` when fetching, creating, or updating issues.

### Triage labels

Use the five default triage labels.
Read `docs/agents/triage-labels.md` when assigning triage status.

### Domain docs

Use a single-context layout: root `CONTEXT.md` and `docs/adr/`.
Before exploring the codebase, read `docs/agents/domain.md`.
